# BATTLESTATS // BGMI Stat Tracker & Esports Certification Engine

BATTLESTATS is a web visualizer and verification engine for Battlegrounds Mobile India (BGMI) players. It allows players to visualize tactical radar ratings, generate 9:16 Instagram/WhatsApp flex cards, and get audited for competitive scrims.

## Features
- **Tactical 5-Axis Radar Chart**: Balances Firepower, Impact, Precision, Survival, and Consistency.
- **Esports Combat Power (ECP)**: Weighted 0–1000 competitive score preventing low-match stat bloating.
- **1-Click Flex Card**: Instant downloadable PNG formatted for Instagram Stories and WhatsApp Status.
- **OCR Screenshot Ingestion**: Architecture for scanning in-game career profile screenshots.

## Tech Stack
- Frontend: HTML5, Tailwind CSS, Chart.js, html2canvas
- Database Schema: PostgreSQL
